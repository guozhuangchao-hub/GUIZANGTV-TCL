# 开机、Home与守护

安装后默认关闭自动进入。纯桌面与应用列表不需要高权限。用户要开机/Home进入归藏时再按设备选择：

- 标准Android TV：standard包声明HOME，系统允许时设为默认桌面，不需要额外守护。
- TCL和忽略默认桌面的固件：TCL包不声明HOME，采用可选窗口守护。两项TCL appops放行后，悬浮窗允许后台打开窗口，WRITE_SECURE_SETTINGS只用于恢复自身无障碍，通知监听绑定用于进程恢复。代码不读屏幕正文、不读取或处理通知；Home键被处理为回归藏。
- 旧小米MiTV-MTSU0一次性start_3rd_app入口仍保留，数字和系统设置仅限已知固件；不是其他品牌的通用开机设置。

## AI辅助启用

先普通安装/验证UI，再沿用用户的自动进入授权给 `tools/tv_setup.py install` 加 `--guard --apply`，它先备份现有服务配置，只追加自己的无障碍和通知监听。TCL需 `APP_AUTO_START` 和 `APP_ASSOC_START`。系统没有某个op时记录为不支持，不猜数字、不改其他应用权限。

可以在“设置→电视与启动→开机自动进入”关闭，开关关闭后不处理Home，也不主动回桌面。主动进入原系统桌面的入口仍保留。用包名启动工具时避开小米CATEGORY_INFO一次性入口，明确启动 `.FrameHomeActivity`。

## 如何验证

完整重启和遥控器待机唤醒分别验证。先取得电源操作授权；重启后先只读观察最后稳定的前台，不能手动启动后称作自启。TCL可能先显示系统主页；不承诺去掉开机动画/广告。

应用或HDMI在前台时不应循环抢回。服务重新绑定可能是调试或更新造成，本分支每次开机最多做一次初始检查，更新当天不凭未知前台立即抢回。未知CEC竞态仍需实机验证。

## 恢复

`python3 tools/tv_setup.py restore --serial SERIAL --backup /PRIVATE/PATH/guizang-before.json --apply` 关闭新启用的守护，移除本次自己的无障碍/通知监听，恢复appops，保留其他新增服务；新授予的WRITE_SECURE_SETTINGS会撤销。之前已有守护时停止自动恢复，按原记录处理，不先写坏旧配置。

若单独改过默认HOME，先按备份恢复原组件。原桌面应一直保留，尤其不能禁用小米PatchWall；不要清除原桌面数据来“重置”。同签名升级保留偏好，签名冲突不自动卸载。恢复本身不重启电视。
